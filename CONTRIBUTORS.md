## GitHub attribution

Listing teammates here credits them visibly, but **does not automatically add them to GitHub's Contributors graph**. For verified GitHub contribution attribution, teammates can contribute commits through their own GitHub accounts, or commits can use their correctly configured author email with permission. Repository access can be shared through **Settings → Collaborators** on GitHub.
